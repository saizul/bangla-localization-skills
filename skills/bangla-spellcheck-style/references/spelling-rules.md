# Bangla Academy standard spelling: the rules behind the checker

The Bangla Academy's প্রমিত বাংলা বানানের নিয়ম (standard Bangla spelling rules, revised over
the years, with the Academy's spelling dictionary) is the reference used by most
Bangladeshi textbooks, newspapers and government offices. A few newspapers keep house
styles; follow the client's standard when it differs. The checker encodes only common,
unambiguous cases.

## 1. ই-কার for non-tatsama words (ি, not ী)

Words that are not tatsama (directly from Sanskrit): tadbhava, deshi, foreign words and
their suffixes take ই/ি.

| Wrong | Right |
| --- | --- |
| সরকারী, দরকারী, বেসরকারী | সরকারি, দরকারি, বেসরকারি |
| বাড়ী, গাড়ী, শাড়ী, পাখী | বাড়ি, গাড়ি, শাড়ি, পাখি |
| জানুয়ারী, ফেব্রুয়ারী | জানুয়ারি, ফেব্রুয়ারি |
| কোম্পানী, চাকরী / চাকুরী | কোম্পানি, চাকরি |
| তৈরী, জরুরী | তৈরি, জরুরি |
| ইংরেজী, বাংলাদেশী, আরবী, ফারসী, হিন্দী | ইংরেজি, বাংলাদেশি, আরবি, ফারসি, হিন্দি |
| কাহিনী, রাণী, কিংবদন্তী, শ্রেণী | কাহিনি, রানি, কিংবদন্তি, শ্রেণি |

Tatsama words keep ঈ: জাতীয়, প্রাণী, সুন্দরী, নারী, শ্রীমতী, দেবী. Do not "fix" these.

## 2. Prefix দুর্ vs দূর

দুর্ (bad, difficult) takes উ-কার: দুর্নীতি, দুর্ঘটনা, দুর্বল, দুর্ভাগ্য, দুর্যোগ, দুর্গ.
দূর (far) takes ঊ-কার: দূরত্ব, দূরবর্তী, দূরবীন.

## 3. Foreign words: no ণ, no ষ

ণত্ব and ষত্ব rules apply only to tatsama words. Foreign words use ন and স.

| Wrong | Right |
| --- | --- |
| ষ্টেশন, পোষ্ট, মাষ্টার, ষ্টোর, ফাষ্ট, ষ্টাফ, লিষ্ট, রেজিষ্ট্রেশন | স্টেশন, পোস্ট, মাস্টার, স্টোর, ফাস্ট, স্টাফ, লিস্ট, রেজিস্ট্রেশন |
| কর্ণার, গভর্ণর | কর্নার, গভর্নর |

Native/tatsama words with ষ্ট are correct: কষ্ট, নষ্ট, স্পষ্ট, দৃষ্টি, সৃষ্টি.

## 4. English "a" (æ) sound: অ্যা

অ্যাপ, অ্যাকাউন্ট, অ্যাডমিন, ক্যাম্পাস. Not এ্যাপ or একাউন্ট (একাউন্ট is common but not
standard; the checker flags only the এ্যা pattern, as info).

## 5. ্য-ফলা and আ-কার

ব্যবহার, ব্যবসা, ব্যবস্থা have no আ-কার after the ্য (pronunciation "bæbohar" comes from
the ya-phala itself). ব্যাংক, ব্যাগ (foreign words) do have it.

## 6. Tatsama compounds and sandhi

| Wrong | Right | Why |
| --- | --- | --- |
| পুরষ্কার | পুরস্কার | পুরঃ + কার |
| উজ্জল | উজ্জ্বল | উৎ + জ্বল |
| মুহুর্ত | মুহূর্ত | |
| শারিরীক | শারীরিক | শরীর + ইক |
| প্রতিযোগীতা, সহযোগীতা | প্রতিযোগিতা, সহযোগিতা | -ঈ + তা -> -ই-তা |
| বুদ্ধিজীবি, শ্রমজীবি | বুদ্ধিজীবী, শ্রমজীবী | -জীবী |
| ভৌগলিক | ভৌগোলিক | ভূগোল + ইক |
| আর্শীবাদ | আশীর্বাদ | আশীঃ + বাদ |
| সমিচীন | সমীচীন | |
| নিরিক্ষা | নিরীক্ষা | নির্ + ঈক্ষা |
| অপরাহ্ন, পূর্বাহ্ন | অপরাহ্ণ, পূর্বাহ্ণ | ণ after র (মধ্যাহ্ন keeps ন) |
| আকাংখা | আকাঙ্ক্ষা | |
| সত্বেও | সত্ত্বেও | |

## 7. Redundant -তা

দারিদ্র্য, সৌজন্য, উৎকর্ষ are already abstract nouns: দারিদ্রতা, সৌজন্যতা, উৎকর্ষতা are wrong.

## 8. Others in the checker

উচিত (not উচিৎ), ইদানীং (not ইদানিং), নিচে (below; নীচ means mean/low), পৌঁছানো/পৌঁছে
(chandrabindu).

## 9. Hasanta and compound words (manual review)

- Avoid unnecessary hasanta at word end (ধর্ম not ধর্ম্, কাল not কাল্), except where
  pronunciation would be misread in foreign words (sparingly).
- Write compound words joined or hyphenated as the dictionary does; the checker does not
  decide spacing of compounds.

## 10. Words the checker does not touch on purpose

- কি / কী: both correct with different uses (see the tone guide).
- লক্ষ (100,000; to notice) vs লক্ষ্য (target): context.
- ঈদ / ইদ: both are in use; follow the client's standard.
- গ্রামীণ, প্রমাণ, কারণ: tatsama ণ, correct.

## Adding a rule

Add `(wrong, right, reason, allow_suffix)` to `SPELLING` in `scripts/bn_style_check.py` only
if `wrong` is never a correct word with another meaning, then add a test line with the
wrong and the right form.
